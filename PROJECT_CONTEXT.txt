## PROJECT OVERVIEW

A production‑ready full‑stack portfolio platform for a female engineering student/fresher.  
Two separate experiences on separate subdomains:

| Surface | URL | Visibility |
|---------|-----|------------|
| Public Portfolio | `yourdomain.com` | Open to all visitors |
| Admin Dashboard CMS | `admin.yourdomain.com` | Hidden — no links from public site |

Both are served from a **single Next.js 15 monorepo** using route groups.

## DATA FLOW
- **Portfolio** → Server Components fetch from MongoDB, ISR revalidate.  
- **Admin CMS** → Client Components, RHF + Zod, API routes, CRUD.  
- **AI Chat** → `/api/chat` → Anthropic SDK → MongoDB conversation store.  
- **Analytics** → `/api/analytics` → MongoDB aggregation → Admin dashboard.

## AUTH STRATEGY
- CredentialsProvider (email + bcrypt password)  
- JWT sessions (24h expiry)  
- `requireAdmin()` for API routes  
- Role system: `super_admin > admin > editor`
